# Перенос обновления

Пакет относится только к «Сиқыршы», база — `mage-prototype` на `26e8fde`.
`main` содержит другой проект («Маэстро»), его не заменять.

## Сохранить коммиты (предпочтительно)

Во внешней папке ZIP лежит `mage-improvements.bundle`. В существующем клоне:

```sh
git fetch /полный/путь/mage-improvements.bundle improve-mage-controls:review-mage-improvements
git switch review-mage-improvements
npm test
```

Проверить `MANUAL-CHECK.md`, затем отправить эту ветку и сделать PR в `mage-prototype`.
Если ветка `mage-prototype` уже изменилась, сначала сравнить изменения и разрешить конфликты,
а не перезаписывать работу другого участника.

## Без Git

В папке `project` лежит полная версия приложения с моделью и WASM. Её можно передать
помощнику для переноса в репозиторий. Историю лучше импортировать из bundle.

Для текущей схемы GitHub Pages папка `/mage/` должна содержать содержимое `project`:
`index.html`, `css`, `js`, `assets`, `models`, `vendor`. Соседний проект в корне не удалять.
Проверить реальную схему публикации ветки gh-pages перед обновлением. Автодеплой из
mage-prototype не предполагается. Эти изменения ещё не опубликованы.
