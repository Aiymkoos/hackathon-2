# Отчёт проверки доработки

## Пройдено

`npm test`: 17 тестов Node test runner, 0 ошибок, плюс исходный набор проверок геометрии.

- Все 16 именованных примеров геометрии и ошибок прошли.
- Случайные каракули: принято 4/200 в обычном режиме, 1/200 в строгом; укладывается в исходные пороги.
  Это **не** измерение точности на реальных руках.
- 160/160 синтетических дрожащих рун приняты в своей категории.
- Три дополнительных мусорных траектории отклонены.
- Повтор одного наблюдения камеры не подтверждает позу и не начинает штрих.
- Старт рисования работает на синтетических 10/15/30/60 fps.
- Краткая и длительная потеря руки не склеивают линию и не создают ошибку руны.
- Потеря руки приостанавливает противников, огонь, урон и заряд.
- Удержание ладони применяет один взрыв; отсутствующая рука не проходит Академию.
- Полная симуляция боя достигает победы через три волны и босса; отдельная — поражения.
- Вызовы отрисовки меню/Академии/боя/итогов проверены тестовым Canvas-контекстом
  при 1280×800, 390×844, 844×390: нет исключений и нечисловых координат.
- Worker-поток проверен с тестовым Worker/детектором: один кадр в работе, результат потребляется
  один раз, fallback при ошибке, освобождение bitmap после закрытия, обработка ошибки inference.

## Не подтверждено

Реальная камера, скорость/точность MediaPipe на ноутбуках и телефонах, настоящий GPU/CPU
в Web Worker, звук и полное визуальное прохождение в браузере.
Управляемый браузер среды не открыл локальный HTTP-preview, а открытие file:// запрещено.
Другой браузер для обхода ограничения не использовался. Canvas-тест не является скриншотным тестом.

Запись в GitHub через подключённый доступ возвращает 403 Resource not accessible by integration.
Поэтому публичная версия сайта не обновлена. Пакет содержит готовые изменения, тесты и историю.
