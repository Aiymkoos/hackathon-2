# Сиқыршы — хранитель древней степи

Браузерная игра для ADMIT HACKATHON «Камера вместо джойстика».
Одной рукой начертите знаки, защитите печать от трёх волн жынов и победите Айдаһара.
Направление: игра. Основной сценарий: камера → поза/траектория → заклинание → результат и рекорд.

## Запуск

Сборка и установка npm-пакетов для игры не нужны. Требуется современный браузер с камерой,
WebAssembly и Canvas 2D. Рекомендуется сначала проверить Chrome/Edge на устройстве команды;
работа Safari и камеры телефона пока не подтверждена устройствами.

```sh
python3 -m http.server 5173
```

На Windows можно использовать `py -m http.server 5173`.
Открыть `http://localhost:5173`. Сначала нажать «Начать испытание» и разрешить камеру:
системное разрешение браузера подтверждается обычным способом. Далее меню и игра управляются жестами.
Для телефона/публичного доступа нужен HTTPS. Двойной клик по `index.html` не подходит.
Разместить на статическом хостинге **все** папки, включая `models` и `vendor`.
Пути относительные: проект можно разместить в `/mage/`.

## Управление

Покажите **одну руку**, кисть целиком, при ровном освещении. Можно играть сидя.

| Жест | Действие |
| --- | --- |
| Вытянут указательный, остальные согнуты | Навести курсор; в игре рисовать руну |
| Навести палец на кнопку и удерживать | Выбрать меню/повторить игру |
| Большой палец вверх | Быстрый старт (при первом запуске — Академия) |
| Кулак | Щит от огня |
| Открытая ладонь 1,2 секунды при полной силе | Взрыв, поражающий врагов |

Для начала рисования остановите палец на 140 мс: золотое кольцо показывает готовность пера.
Нарисуйте руну. Круг и треугольник могут сработать сразу; для галочки и молнии
остановите палец примерно на 420 мс или смените позу. После применения переместите палец
к новому началу и снова ненадолго остановитесь. На маленькой/далёкой руке минимальный
размер руны адаптируется. Руны: круг (лёд), треугольник (огонь), молния (гроза), галочка (ветер).
Знак над противником показывает, что требуется сейчас. Одна руна поражает всех подходящих врагов.

Академия учит жестам и четырём рунам. Во второй волне есть безопасный пробный выстрел для щита.
В финале — босс, после победы/поражения — счёт, точность, активное время, советы и локальные рекорды.
Если камера теряет руку, бой останавливается. После возвращения даётся короткое время приготовиться.

## Обязательный режим «ошибка»

- Незамкнутая фигура: «Верни палец к началу» и визуальная отметка разрыва.
- Сплющенный круг: конкретная подсказка увеличить высоту.
- Неправильное количество углов: подсказка про недостающие изломы.
- Неправильная поза: названия пальцев, которые нужно согнуть/выпрямить.
- Рука далеко, слишком близко или на краю: подсказка поправить положение.
- Камера потеряла руку: незавершённая попытка отменяется **без штрафа**, а не считается плохой руной.

`js/runes.js` анализирует форму, размер, замкнутость и углы. `js/gestures.js` использует
геометрию суставов. Это собственные правила поверх точек MediaPipe; модель не знает правил игры.

## Техническое устройство

- Чистые HTML/CSS/ES modules, Canvas 2D и Web Audio, без сервера/API-ключей.
- MediaPipe Hand Landmarker: 21 точка одной руки, режим VIDEO.
- `js/tracking-worker.js`: распознавание вне основного потока; одновременно только один кадр,
  очередь не накапливается. GPU, при невозможности — CPU.
- `js/tracker.js`: при недоступности worker или ошибке используется ограниченный по частоте
  совместимый режим на основном потоке. Ускорение зависит от устройства и не измерено на реальной камере.
- `js/main.js`: только свежие наблюдения обновляют Input; отрисовка работает отдельно.
- `js/input.js`: сглаживание, стабилизация поз, начало/конец штриха, отмена при потере руки.
- `js/scenes/`: меню, Академия, бой, результаты.
- `assets/steppe.svg`, `js/scenery.js`: фон, слои степи, свет и каменный круг.
- `?diagnostics`: режим обработки, длительность последнего inference и число кадров для проверки на устройстве.
- `?debug`: симуляция без камеры/загрузки модели. Зажатая мышь — перо, F — кулак, P — ладонь,
  U — большой палец. Это отладка, **не доказательство распознавания камеры**.

Кадры обрабатываются локально и не отправляются приложением на сервер. Модель и WASM
поставляются вместе с сайтом. Шрифты стартового экрана загружаются из Google Fonts,
при недоступности используются системные. Рекорды хранятся в localStorage этого браузера.

## Тесты

Node.js 22+; внешние тестовые зависимости не требуются:

```sh
npm test
```

- Геометрия: эталоны и ошибки, 400 синтетических каракулей, 160 дрожащих рун.
- Ввод: повторные кадры, частоты 10/15/30/60 fps, потеря и возвращение руки.
- Бой: пауза, удержание ладони, полное прохождение волн до победы, поражение.
- Worker: отсутствие очереди, однократное получение результата, fallback и освобождение кадров.
- Canvas: вызовы экранов на размерах 1280×800, 390×844, 844×390 с тестовым контекстом.

Границы проверки подробно указаны в `TEST-REPORT.md`. Тестовые точки и подменённая модель
не заменяют проверку реальной руки. Перед сдачей пройти `MANUAL-CHECK.md`.

## История и готовые компоненты

Исходная база этой доработки — существующая ветка `mage-prototype`, commit
`26e8fde`. История сохранена; доработка находится в отдельных коммитах.
Дата создания репозитория сама по себе не доказывает дату написания основной логики:
команда должна проверить исходную историю на соответствие старту 28 сентября 07:00 UTC+5
и честно указать любые свои более ранние заготовки.
Готовые компоненты: MediaPipe (см. `vendor/mediapipe/README.md`), браузерные API,
контурные иконки на основе Lucide (ISC). Нарисованные магические знаки — художественные,
не заявление об исторической письменности.

Ветка `main` содержит «Маэстро». Этот проект не должен заменять её случайным копированием.
Инструкция переноса изменений: `IMPORT.md`.
