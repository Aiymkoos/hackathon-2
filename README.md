# 🎼 Маэстро — дирижируй оркестром через веб-камеру

**Направление:** свободный вариант — виртуальный дирижёр.

Встаньте (или сядьте) перед веб-камерой и дирижируйте оркестром из пяти групп. Музыка по-настоящему идёт в темпе ваших взмахов: машете быстрее — оркестр ускоряется, останавливаетесь — музыканты ждут. Широкие взмахи звучат громко, маленькие — тихо. Прямой левой рукой вы даёте вступление группам, а в конце поднимаете руки (фермата) и резко опускаете их, чтобы снять оркестр. Зрители аплодируют, а критик ставит оценку.

Клавиатура и мышь не нужны: даже кнопки меню нажимаются рукой («наведи и подержи»). Браузер требует только одного клика «Включить камеру и звук», чтобы разрешить камеру и звук.

## Как запустить

**Онлайн:** ссылка на деплой — _будет добавлена_.

**Локально** (нужен Python 3 или любой статический сервер):

```bash
git clone https://github.com/Aiymkoos/hackathon-2.git
cd hackathon-2
python -m http.server 5173
```

Откройте <http://localhost:5173>, нажмите «Включить камеру и звук» и разрешите доступ к камере. Нужен современный браузер (Chrome, Edge, Firefox, Safari) и интернет: модель MediaPipe загружается с CDN. Камера работает только на `localhost` или по `https`.

## Сценарий

1. **Меню:** наведите правую руку на кнопку и подержите.
2. **Репетиция (7 шагов):** встать в кадр → доля → forte → piano → вступление → фермата → снятие. На каждом шаге подсказки об ошибках.
3. **Концерт:** «Ода к радости» Бетховена (21 такт, 5 групп оркестра). Внизу лента партитуры показывает, где нужно играть громко или тихо, какая группа вступает и где фермата.
4. **Итоги:** звёзды, баллы по четырём навыкам, самая частая ошибка с советом и таблица лучших концертов.

## Распознаваемые движения

| Движение | Действие |
|---|---|
| Правая рука вниз-вверх (каждая нижняя точка — доля) | Оркестр играет следующую долю, темп берётся из ваших взмахов |
| Широкий или маленький взмах | Громкость оркестра: forte, mezzo-forte, piano |
| Прямая левая рука, указывающая на группу | Вступление группы: флейты, литавры или трубы |
| Обе руки над головой | Фермата: оркестр тянет финальный аккорд |
| Резко опустить обе руки после ферматы | Снятие: оркестр замолкает, звучат аплодисменты |
| Правая рука над кнопкой ~1 секунду | Нажатие кнопки меню |

## Режим «ошибка» (твист)

Приложение замечает неточные движения и говорит, как их исправить. Подсказка появляется над лентой партитуры, а сама ошибка видна ещё и на сцене: музыканты с «?», красная подсветка, пульсирующее кольцо у группы, которая ждёт вступления.

| Что не так | Как замечаем | Подсказка |
|---|---|---|
| Темп выше 132 или ниже 72 ударов в минуту | Медиана интервалов между долями | «Слишком быстро — оркестр не успевает. Дирижируй спокойнее» |
| Дирижёр ускоряется или замедляется | 4 интервала подряд меняются в одну сторону больше чем на 15% | «Ты ускоряешься — держи ровный темп» |
| Неровные взмахи | Коэффициент вариации интервалов больше 0,22 | «Взмахи неровные — держи одинаковый ритм, как метроном» |
| Громкость не совпадает с партитурой | Размах взмаха в ширинах плеч сравнивается с отметкой p/mf/f | «Здесь piano (тихо) — делай маленькие взмахи у груди» |
| Рука слишком низко | Нижняя точка взмаха намного ниже плеч | «Рука слишком низко — дирижируй перед грудью» |
| Вступление согнутой рукой | Угол в локте меньше 145° | «Выпрями левую руку — так флейты поймут, что это им» |
| Указал не на ту группу | Луч от плеча через запястье попал в другую группу | «Это литавры, а вступают флейты — укажи на них» |
| Вступление раньше времени | Позиция в партитуре раньше нужного такта | «Литавры вступают позже — в такте 9» |
| Пропущенное вступление | Группа не получила вступления вовремя | «Флейты ждут вступления! Укажи на них прямой левой рукой» |
| Фермата одной рукой | Над головой только одно запястье | «Подними и вторую руку выше головы» |
| Медленное снятие | Руки опускались дольше 0,45 с | «Опускай руки резко, одним движением» |
| Плохое положение в кадре | Плечи не видны, человек слишком далеко или близко | «Отойди от камеры — рукам нужно место для взмахов» |

## Собственная логика распознавания

MediaPipe даёт только 33 точки тела. Всё остальное — собственный код команды в [`js/conductor.js`](js/conductor.js):

- **Доля (иктус):** скорость запястья по вертикали, нижняя точка засчитывается, когда рука развернулась вверх. Порог шума отсекает дрожание.
- **Нормировка по ширине плеч:** все расстояния в «ширинах плеч», поэтому логика работает одинаково близко и далеко от камеры.
- **Фильтр One Euro** ([`js/filters.js`](js/filters.js)) убирает дрожание точки руки без заметной задержки.
- **Темп и ровность:** медиана интервалов, коэффициент вариации, обнаружение ускорения или замедления.
- **Указание:** угол в локте + вытянутость руки + луч «плечо → запястье» с попаданием в группу по угловой ошибке.
- **Фермата и снятие:** автомат состояний «руки вверху → опускаются → ниже плеч» с замером времени.
- **Следование за дирижёром** ([`js/music.js`](js/music.js)): позиция в партитуре идёт с темпом дирижёра, но не убегает больше чем на долю вперёд от последнего взмаха, поэтому оркестр ждёт, если дирижёр остановился.
- **Оркестр синтезируется в браузере** (Web Audio): скрипки, виолончели, флейты, трубы, литавры, реверберация концертного зала и аплодисменты. Аудиофайлов нет.

## Бонусы

- Таблица лучших концертов (localStorage).
- Звук и визуальные эффекты: светящийся след палочки, луч вступления, ноты над играющими группами, зрители, которые качаются в такт и встают в финале, аплодисменты.

## Структура

```
index.html           стартовый экран
css/style.css
js/main.js           камера → MediaPipe → анализ → сцена → отрисовка
js/tracker.js        камера и MediaPipe Pose Landmarker
js/conductor.js      анализ движений дирижёра (собственная логика)
js/filters.js        фильтр One Euro
js/piece.js          партитура «Оды к радости» для 5 групп
js/music.js          синтез оркестра и следование за темпом
js/stage.js          отрисовка сцены
js/effects.js        частицы и вспышки
js/ui.js             подсказки и кнопки «наведи и держи»
js/store.js          рекорды
js/scenes/           меню, репетиция, концерт, итоги
js/debug.js          режим разработчика
tests/               тесты логики дирижёра
```

## Для разработчиков

- Тесты логики (Node.js 18+): `node tests/conductor.test.mjs`.
- Режим отладки без камеры: откройте `http://localhost:5173/?debug`. Мышь — правая рука, `1`/`2`/`3` — указать на трубы/флейты/литавры, `B` — согнутая рука, `U` — фермата.
